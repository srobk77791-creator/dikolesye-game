# Проверка 0.11

Локальные проверки; это не публичный deploy и не нагрузочное тестирование сервиса.

- `npm test`: 270 проверок. Engine 91, social/PvP 55, protocol 7, world 75, expansion 42.
- Expansion: полный квадрат, море/12 ледяных островов, полный дроп ресурсов/монет, подбор другим игроком, отсутствие повторного дропа, отложенное возрождение, дерево +1/10, разрушение стен разными инструментами, порядок цены/HP, события звука/частиц, урон волка +20%, чума/лекарство/шляпа, лодка и позиция после проверки сохранения, HP/70 урона/предупреждение/защита самурая, ледяное замедление, награды, азиатские постройки/сундуки и восстановление.
- Отдельный тест переноса snapshot 0.9 → 0.11: 10 проверок профиля, ключа, координат, инвентаря, монет, клана, постройки, удаления лагерного костра и отсутствия повторного сдвига.
- Точный плоский Render-каталог: `npm ci --omit=dev`, `npm test`, запуск Node и `/health` с version 0.11.0.
- Реальный локальный Node/WebSocket: вход из Chromium, меню версии, инвентарь, строительство, HUD без ошибок JavaScript.
- Детерминированные браузерные сцены с подставленными серверными кадрами: чумной лес/Азия/море на 1440×900 и 390×844; ледяной остров, три степени повреждения стены, смерть, рецепт лекарства и мобильный рюкзак. 11 снимков проверены визуально; исправлены перекрытия статусов/босса и декор за краем льда. Ошибок JavaScript не обнаружено. Подставленные сцены не заменяют реальную многопользовательскую игру.
- Полные исходники: Cloudflare `npm run cf:check` (dry-run); публичный deploy/аккаунт не проверялись.

Не проверено: доступность из РФ/Крыма, сохранность временного диска Render, нагрузка 12/32 игрока, игровой баланс на длинной сессии, все реальные модели телефонов. Низкий FPS/сетевые обрывы не исключаются. Платные сервисы/постоянная внешняя база не подключались.
