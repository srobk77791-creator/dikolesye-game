# Диколесье 0.10

Обновление проверено локально, но не опубликовано на сайте владельца.

## Карта и спавн
Основной биом 10000 × 10000. Слева зима, справа болота, сверху джунгли, снизу пустыня — по 6500 × 6500. Внешний габарит крестообразного мира — 23000 × 23000; углы между регионами непроходимы. Использовано последнее уточнение 6500, не первоначальное 5000.

Новые герои и возрождение — только лес, зима, пустыня. Повторный вход существующего профиля сохраняет его последнюю позицию, даже если он вышел в джунглях/болотах. Центральный лагерь, бесплатный костёр и лагерная зона PvP-защиты удалены. Защита на 5 секунд после появления сохранена. После смерти теряется 25% расходников, снаряжение остаётся.

Грунт, растения и вода различаются по биомам. Ресурсы создаются участками по мере исследования, участки сохраняются и не размножаются после перезапуска. Используется пространственная сетка для столкновений. Ограничение ресурсов — 12000, воды — 150 водоёмов. Это прототип с ограниченной плотностью, не бесконечный процедурный мир.

## Мобы
Три региональные разновидности на биом, 15 всего:
- Лесной волк, олень, лесной заяц.
- Полярный волк, снежный заяц, тундровый як.
- Крокодил, болотный слизень, болотная стрекоза.
- Ягуар, дикий кабан, попугай.
- Скорпион, песчаная змея, скарабей.

Разные изображения, здоровье, скорость. AI опирается на существующие модели хищника/мирного/летающего животного/слизня, а не на 15 отдельных новых систем поведения. Популяция появляется около активных игроков: около 12 рядом с игроком, около 100 всего. Дальние обычные мобы удаляются; боссы сохраняются. Питомцев нет.

## Камера, звук, строительство
Позиции буферизуются на 120 мс и интерполируются между серверными кадрами; камера дополнительно сглажена. Повороты идут по кратчайшему углу. При переносе/возрождении буфер сбрасывается. Это уменьшает сетевую ступенчатость, но добавляет небольшую визуальную задержку и не гарантирует отсутствие сетевых обрывов/низкого FPS.

Звуки серверных событий: взмах, выстрел, попадание, урон, добыча, строительство, победа. Web Audio синтезирует шум/осцилляторы; отдельных записанных аудиофайлов нет. Нажатие «Играть» разблокирует звук. Настройки сохраняются: если звук ранее отключили, включите его и громкость в настройках. Близкие события слышны в пределах 900 единиц, дальние тише.

15 стен вместо 9: добавлены ледяной, песчаниковый, саманный, джунглевый, базальтовый, укреплённый блоки. Рецепты используют существующие материалы. Костёр, сундук, турель сохранены. Более подробные пиктограммы кнопок, состояния фокуса/нажатия. Подписи мобов не перекрывают имя близкого игрока и соседние подписи. Выбранный рецепт остаётся видимым после обновления окна.

Сохранены чат `/` → Enter → реплика над игроком на 10 секунд, 40 слотов, кланы/PvP. Монеты тестовые игровые, не реальные деньги. Нет платежей, магазина, доната, Google-входа, полноценной модерации/администрации. По умолчанию 12 игроков; нагрузка 12/32 не проверена. Баланс биомов требует теста с друзьями.

## Render: простой архив без папок
В отдельном Render-архиве index.html лежит в корне рядом с server.cjs, engine.cjs, room.cjs и новым world.cjs. Загрузи ВСЕ файлы в корень того же GitHub-репозитория, Commit changes, затем обнови существующий Render-сервис.

Runtime Node, Node.js 22; Root Directory пусто; Build Command `npm install --omit=dev`; Start Command `npm start`. Не выбирай платный тариф автоматически. После Deploy latest commit открой прежний адрес и Ctrl+Shift+R; в меню v0.10 Online. Старый public/index.html можно оставить: сервер предпочитает новый корневой index.html.

Локально: npm install --omit=dev, npm test, npm start, затем http://localhost:3000. Не открывай HTML двойным кликом. Переменные PORT/HOST/MAX_PLAYERS/DATA_DIR. Тесты в Render-архиве переименованы test-engine.cjs и т. п., чтобы не требовать папок.

Бесплатный Render может потерять локальный прогресс при deploy/перезапуске. Внешнее постоянное хранилище этим обновлением НЕ подключено. Не обещай сохранность мира на временном диске.

## Старые миры и полные исходники
Если старый snapshot доступен, координаты мира 0.9/0.8.1 сдвигаются на +6500 по обеим осям в основной биом. Профили/ключи, монеты, инвентари, кланы и пользовательские постройки сохраняются, лагерный костёр удаляется. Метка версии предотвращает второй сдвиг. Сделай резервную копию world.json перед обновлением постоянного диска.

Полные исходники используют public/index.html, test/*, cloudflare/*. Для Cloudflare имя Worker, Island, v1 и main-v08 не менялись. npm install, затем npm run cf:deploy для уже авторизованного владельца. Dry-run прошёл, публичная публикация/аккаунт не проверялись. В упрощённом Render-архиве Wrangler/Cloudflare нет: для Render они не нужны.
