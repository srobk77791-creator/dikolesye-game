# Диколесье 0.11

Это локально проверенное обновление, НЕ автоматическая публикация на GitHub или Render.

## Обновление Render

Используйте «Диколесье-0.11-Render.zip». В нём все файлы в корне, без вложенных папок.
1. Распакуйте архив. Загрузите ВСЕ файлы в корень именно того GitHub-репозитория, который подключён к существующему Render-сервису. Подтвердите замену и Commit changes. Не загружайте ZIP вместо исходников или node_modules.
2. В Render: Web Service, Runtime Node; Root Directory пусто; Build Command `npm install --omit=dev`; Start Command `npm start`. Node закреплён на 22.x. Не выбирайте платный тариф автоматически.
3. Manual Deploy → Deploy latest commit. Проверьте новый commit и успешный запуск, не только Build successful.
4. Откройте прежний адрес и Ctrl+Shift+R. В меню **v0.11 Online**. На телефоне обновите страницу.
5. Проверка адреса с `/health`: `version: 0.11.0`, `rulesVersion: 3`, `worldSize: 23000`. Другая версия означает старую сборку.

Нельзя обновить только README: нужны index.html, engine.cjs, world.cjs, room.cjs, server.cjs, package.json и остальные файлы архива. Сервер предпочитает корневой index.html; старый public/index.html можно оставить. npm сам устанавливает зависимости.

## Карта и спавн

Весь квадрат 23000 × 23000 теперь заполнен. Центральный лес 10000 × 10000 сохранён; зима слева, болота справа, джунгли сверху, пустыня снизу — по 6500 × 6500. Спавн и возрождение только в лесу, зиме, пустыне; повторный вход живого профиля сохраняет позицию.

Бывшие пустые углы:
- Северо-восток: чумной лес, новые руды, травы и богатый лут.
- Юго-восток между пустыней и болотами: Азия, сакуры/бамбук, нефрит, небольшие дома с сундуками, арена самурая.
- Северо-запад и юго-запад, над и под зимой: глубокое море. Две области суммарно образуют крупнейшую новую зону. 12 ледяных островов с льдом и морозными кристаллами.

Новые угловые прямоугольники по 8250 × 8250. На пересечениях приоритет у исходных пяти биомов. Ресурсы генерируются участками, до 24000 узлов; это ограниченный прототип, не бесконечный мир.

Лодка: 24 дерева, 6 ткани, 4 железа. Используется автоматически в глубокой воде, пока лежит в сумке. Без неё вход блокируется. На суше герой выходит автоматически. Ледяные острова малонаселённые: до двух обычных мобов поблизости. Лёд и морозные кристаллы добываются киркой.

## Чума и предметы

Заражение в чумном лесу без защиты растёт на 6%/с. От 20% теряется 4 HP/с; обычная регенерация немного компенсирует урон. Удары чумных мобов добавляют заражение. За пределами леса оно медленно падает.
- Лекарство: 4 травы, 4 ягоды, 1 кристалл, 1 вода. Используйте через действия предмета в сумке. Снимает чуму и даёт 120 секунд иммунитета; HP не восстанавливает.
- Античумная шляпа: 8 ткани, 6 кожи, 4 кристалла. Нужно НАДЕТЬ на голову. Защищает от заражения и даёт 8% защиты от ударов.
- Ледяной меч: 58 урона; замедляет мобов на 35% на 4 с. Рецепт: 12 льда, 8 морозных кристаллов, 8 железа, 6 дерева.
- Чумной клинок: 56 урона, 0.26 с между ударами; требует чумную руду. Отдельного заражения игроков этим клинком нет.

## Мобы и самурай

К прежним 15 региональным вариантам добавлены восемь: чумной хищник, заражённый странник, чумной ворон; тигр, макака, разбойник; ледяной тюлень и полярная чайка. Урон обычных мобов и старых боссов увеличен на 20%.

Самурай у 18800,18800: 1100 HP, базовый удар 70 HP (броня/щит снижают итог). Рисунок в четыре раза крупнее обычного человеческого моба: броня, шлем, красные глаза, катана. AI: патруль, преследование, подготовка удара 0.6 с, атака, восстановление, уклонение от снарядов, защита. Предупреждение показывает сектор атаки. Это конечный автомат, не обучаемый ИИ. После победы флаг сохраняется, самурай автоматически не возрождается. Лут на земле: 50 D-coins, катана, нефрит, лекарства; доступен всем.

## Смерть и общий лут

Игрок и мобы исчезают с поворотом, уменьшением, затуханием и частицами. При отключённой анимации остаётся затухание. Игрок возрождается примерно через 1.1 с, с защитой 5 с. До возрождения нельзя атаковать, подбирать или перекладывать предметы.

Из ВСЕХ 40 ячеек выпадают все материалы, еда, вода, боеприпасы, бинты/зелья/лекарства и все D-coins. Правило 25% удалено. Инструменты, оружие, броня, лодка и готовые строительные предметы остаются: теряются ресурсы, не всё снаряжение. Лут мобов тоже лежит на земле, а не начисляется убийце автоматически.

Любой игрок может подобрать ближайшую стопку клавишей E или кнопкой руки. При полной сумке остаток остаётся на земле. Монеты увеличивают счётчик. Рисунок D-coin оригинальный, не скопирован из Dynast.io. Монеты тестовые игровые, не реальные деньги.

## Стены и добыча

Стены можно повреждать кирками, топорами и любым оружием ближнего боя, включая собственные стены. Выберите инструмент, наведитесь, ударьте. Тихий звук, дрожание, осколки. При 55% потери HP — трещины, при 90% — сильные трещины и расколотые углы; при нуле блок удаляется. X — отдельная разборка своей постройки.

Прочность 15 стен = 100 + 22 × взвешенная стоимость материалов рецепта: дешёвые слабее дорогих. Старые стены сохраняют процент повреждения при пересчёте HP.

Каждый правильный удар топором даёт 1 дерево в сумку; уничтожение дерева добавляет 10 дерева на землю. Кирка/оружие не дают дерево за удар. Шахтёр не удваивает финальные 10. Другие ресурсы при завершении добычи тоже выпадают на землю.

## Сохранения и ограничения

Snapshot version 3, rulesVersion 3, layoutVersion 2. У 0.10 координаты не меняются. Для 0.9/0.8.1 сдвиг +6500 по обеим осям выполняется один раз. Профили/ключи, кланы, монеты, инвентари и постройки сохраняются, ЕСЛИ сервер имеет доступ к прежнему snapshot. Старый лагерный костёр удаляется. Сделайте резервную копию world.json на постоянном диске.

Бесплатный Render с временным диском может потерять прогресс при deploy/перезапуске. Внешнее постоянное хранилище НЕ подключено. Нет гарантии доступности хостинга из любой страны. Render-архив не требует Cloudflare; файлы Cloudflare есть только в полном исходном архиве и сами по себе трафик через него не направляют.

Сохранены чат `/` → Enter → реплика 10 с, 40 слотов, кланы/PvP, интерполяция 120 мс, настройки звука. Для звука нажмите «Играть» и проверьте громкость. Низкий FPS/сетевые разрывы не устраняются одной интерполяцией. Нет платежей, доната, магазина, Google-входа, полноценной модерации. По умолчанию 12 игроков; нагрузка 12/32 не проверена. Баланс новых биомов требует тестов с друзьями.

## Локально и полные исходники

`npm install --omit=dev`, `npm test`, `npm start`, затем http://localhost:3000. Не открывайте HTML двойным кликом. Переменные PORT, HOST, MAX_PLAYERS, DATA_DIR. В Render-архиве тесты в корне; в полном — test/.

Полные исходники сохраняют public/, test/, cloudflare/. Cloudflare для уже авторизованного владельца: npm install, npm run cf:deploy. Имена Worker, Island, v1 и main-v08 не менялись. Dry-run не является публичным deploy; вход/аккаунт и публикация не выполнялись.
