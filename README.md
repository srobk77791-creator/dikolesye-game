# Диколесье 0.9 — карта, плавные повороты и реплики

Это исходники клиента и серверного прототипа. Проверено локально, в том числе в среде Cloudflare Workers/Durable Objects. **Это обновление 0.9 ещё не опубликовано мной в твоём аккаунте. Публикацию выполняет владелец через deploy.**

Начни с файла **НАЧНИ-ЗДЕСЬ.txt**. GitHub не нужен.

## Изменения 0.9
- Карта: 4000 × 4000 вместо 3200 × 3200. Старые объекты сохраняют координаты; при загрузке старого мира ресурсы добавляются только в новых полосах карты. Размер записывается в сохранение, чтобы не повторять расширение после перезапуска.
- Плавные повороты игрока, других игроков и мобов: кратчайший путь между углами, включая переход через −π/π. Отображение обновляется между серверными кадрами; правила удара и направления на сервере не меняются.
- `/` открывает компактный ввод. Enter отправляет и закрывает его. Сообщение видно над отправителем 10 секунд; новая реплика заменяет предыдущую. Постоянной панели истории на экране нет. На телефоне — кнопка чата и отправки.
- Реплики клана видны только соклановцам. Сохранены настройки клавиши и отключение чата.
- Камера не выходит за края карты; прицеливание учитывает смещение игрока у границ.
- Питомцы не добавлены.

## Функции предыдущих версий
- Чат: `/` открывает, Enter отправляет, Escape закрывает. Клавиша меняется в Настройки → Управление → Чат: `/`, T, Y, C или Enter. Можно отключить чат. Общий канал и приватный канал клана. Текст до 180 символов; ограничение частоты на сервере. Сообщения показываются как текст, не HTML.
- Кланы: бесплатно 3 места, включая главу. Затем последовательные покупки **5 мест за 10**, **8 за 100**, **10 за 200**, **без лимита за 500 монет**. Каждая ступень оплачивается отдельно (весь путь — 810 монет). Платит глава из своего баланса. Количество участников не превышает количество существующих профилей; «без лимита» не снимает технических ограничений сервера.
- Создание, уникальный тег, приглашения с согласием, список участников, исключение и выход. При уходе главы руководство переходит следующему участнику. Приглашения временные; после перезапуска нужно отправить заново.
- PvP: ближнее оружие и снаряды, броня и щит. Соклановцы не наносят друг другу урон. Радиус безопасного лагеря — 140 игровых единиц, защита после появления/возрождения — 5 секунд. Пока открыты окна и чат, мир продолжает работать.
- Чужие стены можно разрушать вне лагеря. Свои и стены соклановцев защищены от дружеского урона. X разбирает только свою постройку. Турели пока атакуют мобов, не игроков.
- 9 материалов стен: дерево, камень, железо, золото, кристалл, уголь, волокно, ткань, кожа. Прочность и рецепт видны в строительном меню.
- Компактная боковая панель крафта: список слева, детали выбранного рецепта справа. Рюкзак открывается кнопкой, а не занимает экран постоянно. Отдельные кнопки крафта, стройки, рюкзака, кланов и чата. Убрана постоянная большая плашка задания. Меню выхода упрощено.

## Монеты — временный тестовый баланс
Старт: 0. Монеты начисляет только сервер: волк/слизень/скелет — 1, король кабанов — 5, Древний — 10. За убийство игрока монет нет. Это **внутриигровая валюта**, не реальные деньги. Магазин, платежи, донат, Google-вход и возвраты платежей не подключены. Экономику нужно отдельно балансировать.

## Что осталось из прошлой версии
40 слотов (10 быстрых + 30 в рюкзаке), три стартовых предмета (каменная кирка, каменный топор, дубинка), внешность/цвета/скины, факел, день 15 минут, ночь 10. Только подходящий инструмент добывает ресурсы. Оружие разрушает деревья/руду медленно и без добычи. Старый офлайн-мир не импортируется.

## Cloudflare: запуск без GitHub
Нужен свой аккаунт Cloudflare и Node.js 22 или новее. Команды выполняются **в папке с package.json**, не внутри public.

```sh
npm install
npm test
npm run cf:login
npm run cf:deploy
```

`cf:login` открывает авторизацию Cloudflare в твоём браузере. Войди и разреши Wrangler работать с твоим аккаунтом. Пароли и токены никуда в чат не присылай.

`cf:deploy` публикует клиент, Worker и SQLite-backed Durable Object. После успеха терминал выводит настоящий адрес на `workers.dev`; открой именно его. Два разных браузера / обычное и приватное окно — два игрока. Не выдумывай адрес вручную.

Затем проверь: чат между двумя окнами, приглашение в клан, повторный вход, PvP вне лагеря. Начинай с теста для друзей, не с массовой рекламы.

### Локальный запуск перед публикацией
```sh
npm run cf:dev
```
Открой адрес из терминала. Здесь данные хранятся в локальной `.wrangler` — это не публичное хранилище. Локальный мир не переносится автоматически на публичный сервер.

### Сохранения на Cloudflare
Durable Object сохраняет мир, монеты, профили и кланы в своё постоянное хранилище примерно каждые 15 секунд и при отключении игроков. Последние изменения между записями при сбое могут потеряться. Chat history не сохраняется. При отсутствии подключений таймер мира останавливается. Не удаляй Durable Object namespace и не меняй его имя/маршрут случайно: это может создать другой мир или удалить данные. Резервные копии и полноценную административную панель ещё нужно добавить.

Во время игры объект **активен**: тикающая симуляция не использует WebSocket hibernation. Сначала тестируй на Free, следи за лимитами Workers и Durable Objects. Превышение бесплатного лимита может приводить к ошибкам. Не включай Paid автоматически. Цена зависит от сообщений, вычислений, времени активности и хранилища, а не от уникальных посетителей.

По умолчанию — **12 одновременных игроков**, максимальная настройка прототипа — 32. Увеличение требует нагрузочного теста. Один остров и до 256 гостевых профилей; старый неактивный профиль может удаляться при переполнении. Это ограничение прототипа, не готовая MMO.

## Подключить play.swag-hack.ru — позже
Сначала запусти на workers.dev. Для Custom Domain нужна активная DNS-зона домена в Cloudflare.

Если домен ещё не в Cloudflare, **не меняй nameserver вслепую**: сначала нужно проверить и сохранить существующие A/CNAME/MX/TXT-записи, чтобы не сломать сайт и почту.

Когда зона активна: Workers & Pages → dikolesye-game → Settings → Domains & Routes → Add → Custom Domain → `play.swag-hack.ru`. Cloudflare создаёт DNS-запись и сертификат. Если на `play` уже есть запись, сначала нужно выяснить, для чего она используется, а не просто удалять.

Гостевой ключ привязан к браузеру и адресу сайта. Переход с workers.dev на свой домен создаст отдельного гостя. До серьёзного запуска нужны постоянные аккаунты/Google-вход или отдельный безопасный перенос. Не делись гостевым ключом.

## Render / обычный Node.js-сервер
Для уже созданного Render Web Service обнови файлы в подключённом репозитории, сохрани корневую структуру и public/index.html, затем разверни последний commit в том же сервисе. Не создавай второй сервис для этого обновления. Runtime: Node; Build: `npm install --omit=dev`; Start: `npm start`. Выбирай только Free, если нужен бесплатный тариф.

```sh
npm start
```
По умолчанию порт 3000, сервер слушает все интерфейсы. `PORT`, `HOST`, `MAX_PLAYERS`, `DATA_DIR` задаются переменными окружения. Сохранение — `data/world.json`; папка закрыта от выдачи через HTTP. Для Docker подключай постоянный том к `/app/data`. На бесплатном Render локальные файлы теряются при перезапуске/засыпании, поэтому Cloudflare-версия хранит данные иначе.

## Ограничения перед открытым запуском
Нет Google-аккаунтов, доната, чёрного списка чата, жалоб/модерации, полноценной защиты от множества гостевых аккаунтов и готовой панели администратора. Гостевой ключ — bearer credential. Нет обещания бесплатной работы при любом онлайне. Нужно проверить реальную публикацию, задержку до игроков, нагрузку, резервные копии и правила чата. Скриншоты Dynast.io служат ориентиром для структуры меню; клиент использует прежнюю графику Диколесья, а не изображения со скриншотов.

## Производительность 0.8.1
Кэшируются статические деревья/руда/стены, сглаживаются позиции мобов, сервер присылает кадры 10 раз/с. Клиент договаривается о версии протокола 2: неизменившиеся инвентарь, экипировка, постройки, добыча и социальные данные не повторяются, внутренние параметры AI не отправляются. Старый протокол сохраняет полные кадры для совместимости.

Индикатор справа измеряет FPS через requestAnimationFrame и RTT через WebSocket ping/pong. RTT включает задержку браузерной обработки, это не отдельное измерение расстояния до дата-центра. HTTP-ответ из другого региона не показывает задержку конкретного игрока. Нет обещания конкретного FPS.

Имя Worker, класс Durable Object, миграция и ключ main-v08 не изменены. Никакого сброса/переноса мира не выполняется. Высокая задержка из-за далёкого региона требует отдельного решения с переносом данных, а не произвольного переименования комнаты.
